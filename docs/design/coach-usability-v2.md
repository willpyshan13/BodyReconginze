# 单人训练可用性改进

状态：内部逻辑修复及下述交互已按展示的预览继续实现。保持现有暖白、深绿视觉，全程静音，本地文字对话。用户说明当前未连接设备，后续仅做本地构建和回归检查，新增交互尚未实机验证。

## 已有界面的修复

- 俯卧撑计数增加同侧肩髋方向检查，排除站立弯举，保持水平姿态下单侧计数能力。
- 每次完整动作和纠正提示保留时间、组数、完整次数序号及原因。幅度不足属于一次尝试，不冒充已经计数的第N次完整动作。
- 持续左右角度差才生成反馈；单侧输入不推断对称程度。一般下一帧不覆盖刚生成的纠正提示，聊天与暂停保留事件。
- 休息问题不再误匹配为计数问题；无反馈记录时不宣称姿势正确。
- 有效训练时间以近期可靠姿态为依据；视频节奏以视频时间为依据。
- 识别错误保留并暂停，启动失败回到设置；没有完成次数的启动失败不生成训练记录。
- 超出保存的视频分析时间范围时移除骨架并显示未分析提示；不跨接缝或长缺帧区间进行骨架插值。
- 活跃训练保持屏幕常亮；进入后台时关闭聊天并保持暂停。

## 取景准备

打开训练先显示摄像头取景，默认前置，并提供前后切换。取景区域显示该动作所需部位和入镜状态；站位未就绪时不开启有效计时。点击开始后，3秒准备期间仍保留取景。切换镜头时清理未完成动作周期，防止拼接动作。

## 视频进入同一训练流程

训练输入提供摄像头和导入视频。导入视频后，同屏显示画面骨架、完整次数、逐次反馈和“问问教练”；明确标记片中人物及分析范围，不计入本人训练。第一版继续分析前60秒；超出部分可预览但不展示旧骨架。

## 依据记录追问

教练读取本次记录来源、组次和最近纠正事件，用户可追问“刚才哪里要调整”。视频反馈提供静音原片片段回放，范围覆盖反馈时间前2.5秒至后1秒；回放不重新计数。打开对话暂停训练，返回继续；原本手动暂停的训练保持暂停。

预览人物来自内置真人视频，界面中的3/8次、00:18等均为设计示例，不能作为实际测量结果。
