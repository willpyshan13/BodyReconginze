# 手机户外跑步 · 设计方案（待确认）

## 场景与边界
用户随身携带手机在户外跑步，与开发板无关。手机GPS记录轨迹、距离、运动时长、实时及平均配速；不使用摄像头识别跑姿，不虚构心率或热量，不连接大模型，不自动播放声音。沿用已确认的暖白/深绿设计。

## 结构
在训练首页增加户外跑步入口；底部仍为训练、教练、记录。跑步准备支持自由跑、距离目标、时间目标。训练中突出距离、时长、平均配速；次要展示当前配速、目标进度和GPS状态，路线单独查看。大按钮暂停、继续和结束，结束前确认。目标达成只提示，不强制结束。

## 运行状态
定位权限未开启、等待定位、定位就绪、记录中、定位信号弱、暂停、锁屏后台记录、结束确认、已保存、记录空状态。定位不足时实时配速显示不可用；定位中断保留已有数据，标记缺失，不补画轨迹。暂停不累计运动距离及运动时长，恢复时不将暂停期间移动计入。平均配速由有效运动时长和有效距离计算，未满1公里的最后一段单独记录。

## 跑后与记录
总结展示实际距离、时长、平均配速、目标完成状态、路线及每公里分段。记录与原动作训练区分；每条记录应打开自己的详情，不共用固定样例结果。预览数字仅为设计展示，全部注明样例，不写入真实记录。预览中的路线区域为明确占位，不伪造地图或定位。

## 实现时需验证
手机定位权限与后台运行支持；前台可见记录状态；锁屏、切后台、进程中断后的恢复；GPS精度/漂移/异常点过滤；分段与暂停时间计算；地图来源及服务接入方式在实现前确定。地图显示能力与定位记录分离，弱网仍保存可用定位点。不能只靠前台计时器宣称锁屏可持续记录，必须做手机实测。

## 状态
仅出设计与可点击效果预览，尚未开发Android功能。用户确认后才实施、构建和安装。当前不请求真实定位，不连接设备，不访问真实路线数据。
