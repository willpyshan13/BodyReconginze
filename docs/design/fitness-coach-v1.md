# 本地健身教练 · 产品界面方案（待用户确认）

状态：用户已通过“可以，做吧”明确批准本方案，现进入实现。

## 产品方向
以日常训练为主线，采用克制的运动品牌感、大字号数字和清晰的单一主操作。按现有设备竖屏设计，支持平板宽度适配。绿色用于主操作和识别正常，黄色用于需要调整，界面全程静音。应用级导航为训练、教练、记录；模型对比及推理参数移入设置中的调试工具。

## 页面与流程
- 训练首页：开始训练为主要入口；显示手动设置的动作、组数、次数和休息时间，动作库提供五种现有动作。不假装提供自动生成的计划。
- 训练设置：选择动作与目标、摄像头或内置深蹲视频。非深蹲不开放内置示范，缺少摄像头时显示明确的连接提示。确认后进入准备页。
- 准备及训练：以画面为主，明确来源（摄像头/视频演示）、静音、入镜状态。大号次数、当前组数、一个最重要的动作提示；关节角度默认收起。暂停、继续和结束为清晰操作，结束需确认避免误触。
- 组间休息：显示倒计时、下组目标和继续入口。提前继续需要在实现时接入训练状态机，不能只改显示。
- 完成总结：显示实际次数、组数、训练时间和规则反馈；不将幅度/对称指数命名为动作质量评分；提前结束与计划完成区分。
- 教练：独立全屏文字对话，快捷提问置于输入框上方；标明本地预设回复；进度来自真实数据，随机闲聊不得编造训练结果。
- 记录：本人训练与视频演示分开，按动作显示次数、时间和完成状态，进入单次详情；空状态引导开始训练。

## 状态要求
准备倒计时、关键点缺失、无摄像头、暂停、休息、提前结束、正常完成、暂无记录。预览中的训练数字和历史条目均为设计样例，不能写入真实训练记录。预览中的视频帧来自项目已有授权素材。

## 交付边界
设计阶段已制作独立可点击预览和规则文件；用户确认后已进入Android原生界面实现。预览不执行识别、不连接设备、不播放音频。
